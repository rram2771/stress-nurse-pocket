# ❤️ Stress Nurse Pocket

An ADHD-friendly, sketchnote-style reference for the cardiac stress lab: ECG reading, stress testing, Lexiscan and emergencies, plus flashcards.

## 📱 Mobile app
`index.html` is a single-file web app:
- **ECG:** 6 steps, 300 rule, normals, axis thumbs, the MI gang (BIG LII ⬇ • little LI ⬇ • ASS ⬆ • ALL ⬇), coronary arteries, patterns with strips
- **Stress:** test ladder, Bruce, target HR, don't-start / stop criteria, ST changes, echo walls
- **Lexiscan:** timeline, no-go list, rhythm check, monitoring, reversal
- **Emergencies:** ACLS quick look
- **Flashcards:** 88 cards in 6 decks, flip + Again / Got it, progress saved on your device
